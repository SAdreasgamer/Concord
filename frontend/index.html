Case 4 ⚠️ Real Failure Analysis

Honest Breakdown: Table Footnote Detachment & Currency Scaling

A deep dive into where the automated pipeline produced an imperfect result, why it failed, and how the architecture addresses it.

1. The Input Scenario

Delhivery 2022 Prospectus, Page 5 contains financial summary tables where Adjusted EBITDA is printed with superscript footnote (1): "Adjusted EBITDA: (2,345.67) INR Million *(1)*".

2. What Went Wrong (The Failure)

The PDF text extractor (PyMuPDF) extracts stream text line-by-line. The footnote explanation "(1) Excludes share-based payment expenses and one-time IPO expenses" was positioned 40 lines below at the bottom of the page. The LLM parsed the metric as unconditioned EBITDA, omitting the essential footnote exclusions.

3. Consequence on Relation Judging

When matched against the Annual Report's Reported EBITDA (which included share-based payments), the judge classified the pair as a contradiction instead of reconciling it under definition_difference with explicit footnote adjustments.

4. Root Cause & Architectural Remedy

Root Cause: Flattening 2D PDF layout coordinates into 1D linear text strings strips topological proximity between table cells and marginal footnotes.
Remedy: Implemented candidate matching hint tagging (different_scope) and fuzzy registry normalization. Production upgrade: Bounding-box coordinate extraction (PDF table structure trees) to attach cell footnotes before LLM prompt assembly.
